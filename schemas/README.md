# HSDS service validation schema

Human Services Data Specification: an Open Referral resource (https://openreferral.org/).

`hsds-3.2-service.json` derives from the [official HSDS 3.2 compiled service schema](https://github.com/openreferral/specification/blob/3.2/schema/compiled/service.json), retrieved September 14, 2026. Non-validation annotations (documentation, examples and tabular metadata) were removed and whitespace compacted. The retained JSON Schema validation constraints are used offline; no user-supplied schema or remote reference is fetched.
