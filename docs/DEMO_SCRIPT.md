# Demo script — target 3 minutes 30 seconds

Use this as narration or captions. All people, programs, and addresses shown are fictional. Keep the provider badge visible. A guided-mode recording is a product walkthrough, not evidence of live model execution. Replace the intake segment with a successful live Strands run before the final hackathon upload.

| Time | Screen | Narration |
|---|---|---|
| 0:00–0:25 | Overview | “When a community class moves, one change can leave several outdated notices behind. ServiceSignal helps the coordinator keep the right information in circulation. This demonstration uses a fictional community center.” |
| 0:25–0:50 | New update | “Digital Basics is moving for two sessions. The coordinator pastes the message they already have. In this recording, the badge identifies whether interpretation is live or a deterministic example.” |
| 0:50–1:20 | Facts and source | “The proposal names the exact sessions, address, and room. Hours stay unchanged. Source quotations support the extraction; the coordinator confirms the operational facts.” |
| 1:20–1:45 | Approval plan | “Approval is for this exact revision, these destinations, and this end-date notice. The agent cannot approve its own work.” |
| 1:45–2:15 | Progress and public page | “The worker publishes the real controlled website and retrieves the rendered page again. Only matching visible facts produce Verified. Residents can open the notice without an account, or scan its permanent QR link.” |
| 2:15–2:40 | Partner and print states | “The partner here is a simulator. Acknowledgment is different from publication. The PDF is ready, but printed copies remain a manual task. One unresolved copy does not erase a successful website update.” |
| 2:40–3:05 | Expiration | “We advance this isolated demo clock. When the arrangement ends, the notice asks residents to check the next details. It does not assume the old venue is correct.” |
| 3:05–3:30 | Evidence and limitations | “The release tests cover stale approvals, isolation, retries, restart recovery, misleading success responses, PDFs, and expiry. Our next step is a real coordinator pilot. We have not yet measured time saved or prevented trips.” |

## Recording checklist

- Run one clean fictional workspace and keep the provider badge visible.
- Show actual publication and the separately loaded public page.
- Include one ambiguity or partner-failure scenario if time permits.
- Show at least one read-back evidence record and the expiration fallback.
- Hide unrelated applications, account identifiers, keys, and private browser tabs.
- Keep the finished video below five minutes. Upload publicly to YouTube or Vimeo using the entrant's account.
- Do not fabricate live model outputs, partnerships, usage counts, or impact measurements.
