# Research, originality, and attribution

Reviewed September 13, 2026. Vendor pages describe capabilities; they are not independent product tests.

- [Agents for Humans overview](https://agentsforhumans.devpost.com/) and [official rules](https://agentsforhumans.devpost.com/rules): required Strands use, tracks, submission artifacts, schedule, and optional hosting/AgentCore benefits.
- [Open Referral technology overview](https://openreferral.org/about/technology-overview/): community-resource exchange standards, ORServices, and Service Net reconciliation and edit provenance. ServiceSignal does not claim to invent directory synchronization.
- [Open Referral FAQ](https://openreferral.org/faq/): context for community information maintenance and cooperation.
- [Yext Listings](https://www.yext.com/platform/listings): connected distribution and publisher verification. These broad capabilities are not novel to ServiceSignal.
- [Strands structured output](https://strandsagents.com/docs/user-guide/concepts/agents/structured-output/) and [Anthropic provider](https://strandsagents.com/docs/user-guide/concepts/model-providers/anthropic/): structured agent integration, checked against the installed SDK as well.
- [ServiceSignal invoice product](https://www.servicesignal.app/): evidence of an existing unrelated product using the working name. Choose and check a distinct public brand before a broader launch.

Original project code, UI layout, vector illustration/icons, fictional organization, addresses, and fixtures were created for this build. No real community directory data or beneficiary information was copied into the demo. AI coding assistance was used. Python dependencies are declared and pinned; their licenses remain applicable. GitHub Actions are third-party build tools.

The preceding PRD was prepared September 8, 2026, within the published hackathon submission period. Implementation work took place September 13, 2026. Broader market demand, adoption, and reduced wasted trips remain hypotheses.
