## Strongest demonstration story

A library's class moves for two Tuesdays. The agent reads the source and confirmed baseline, identifies missing details, and proposes only supported occurrences. An authorized owner confirms and approves. The worker publishes and independently reads the visible result. The resident opens the QR notice without an account. A partner copy remains explicitly unresolved. When the approved period ends, the public notice requests confirmation instead of asserting an unconfirmed return to the old room.

Proposed pitch: **ServiceSignal helps community coordinators keep temporary program changes accurate from the source message through publication and the next decision.**

[Open Referral](https://openreferral.org/about/technology-overview/) already describes service-data reconciliation and [Yext](https://www.yext.com/platform/listings) provides listings verification. Source evidence, occurrence boundaries, accountable incomplete work and end-date decisions form our focused workflow; individual capabilities are not inventions. Practical differentiation requires coordinator evidence.
